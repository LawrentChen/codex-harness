# 真实资产代码查询

资产代码是查询边界，不要仅凭用户给出的简称拼接交易所后缀。

## 股票、基金和其他常见资产

1. 推断资产名称、资产类型和市场。
2. 查阅对应市场文档，确认用于检索合约的 API。
3. 使用 `rqdatac.all_instruments(...)`、`rqdatac.instruments(...)` 或文档指定的检索接口查找候选。
4. 用名称、类型、交易所、上市状态和日期范围消除歧义。
5. 将确认后的完整 Ricequant 代码传给行情或基本面 API。

用户直接提供完整代码时，也应通过合约信息 API 验证其存在且类型正确。

## 期货

1. 识别期货品种代码，例如沪深 300 股指期货为 `IF`、铜为 `CU`。
2. 查阅期货文档，使用品种代码获取指定日期的可交易合约或主力合约。
3. 根据用户需要选择具体月份合约、主力连续合约或其他连续合约，不自行替换。

## 期权

1. 识别期权类型：期货期权、ETF 期权、个股期权或其他类型。
2. 确认真实标的：
   - 期货期权使用期货品种代码作为标的，例如铜期权对应 `CU`。
   - ETF 或个股期权先通过合约信息 API 找到 ETF 或股票的完整代码。
3. 查阅期权文档，使用标的和查询日期获取实际期权合约。
4. 根据到期日、认购认沽、行权价和交易状态筛选，不编造合约代码。

涉及历史查询时，应使用当时有效的合约集合，不能用当前可交易列表替代历史状态。
