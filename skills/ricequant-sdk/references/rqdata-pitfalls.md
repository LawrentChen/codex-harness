# RQData 常见误用

提交代码前检查以下事项：

1. 调用任何 RQData API 前执行 `rqdatac.init()`。
2. 使用完整且经过验证的 Ricequant 合约代码，不将 `600000` 直接传给需要 `600000.XSHG` 的接口。
3. 交易日历使用官方文档列出的 RQData API，例如 `get_trading_dates`；不要根据其他数据源的函数名猜测 `get_trading_calendar` 等不存在的接口。
4. 区分 RQData 研究环境 API 与 RQAlpha 策略运行时 API。
5. 确认日期参数是否包含端点，以及返回索引或日期列的实际类型。
6. 确认行情频率和复权方式，避免把日线、分钟线、tick 或前后复权结果混用。
7. 查询期货和期权时，先获取真实合约集合，再选择具体合约。
8. 财务和宏观查询先确认字段或因子名称；不要仅凭自然语言猜字段。
9. 先检查返回对象和空结果，再决定如何索引、连接或转换 DataFrame。
10. 用最小标的和日期范围验证 API，再扩大查询规模。
